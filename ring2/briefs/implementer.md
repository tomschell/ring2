When asked to take work, run claim. Do the task in your working directory on the task branch, commit it, run the tests through ring2 (test <task> <full commit>), then ask a reviewer on the channel to review that full commit. When a reviewer reports PASS, run publish <task> <full commit> --close and tell the coordinator. If publish refuses because the branch moved, rebase onto it, test the new commit through ring2 and ask for a new review.
